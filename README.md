## 🚀 Featured Project: PayFlow

**Automated Payment Reconciliation & Billing Data Platform**

A production-inspired data platform for a fictional European fintech. It ingests heterogeneous payment provider files (CSV, JSON, API), standardizes them, reconciles against internal records, enforces data quality, and produces merchant billing analytics.

**Highlights:**

- 🏗️ **Star-schema data warehouse** in MySQL 8.0
- 🔁 **ETL pipeline** in Python + pandas
- 🧮 **SQL reconciliation engine** with CTEs and window functions
- ✅ **Data quality checks** + rejected-record handling
- 🧪 **pytest + GitHub Actions CI/CD**
- 📊 **dbt models + tests**
- 📈 **Streamlit dashboard**

🔗 [View repository](https://github.com/DenitsaNes/payflow-data-platform)
